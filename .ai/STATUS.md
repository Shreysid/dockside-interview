# Project status

Dockside serves a responsive typed interview workspace at the loopback origin. It loads a three-problem catalog, holds a separate draft and transcript for each problem while the page is open, submits the current code with each typed, check, and finish action, and displays final feedback.

The locked uv environment and HTTP tests cover typed turns, the catalog, static assets, and the loopback access policy. Chrome can record and transcribe short microphone clips into an editable response draft. Hands-free capture, browser playback, Kokoro synthesis, and bounded model conversation history are pending. Physical microphone QA is pending.
